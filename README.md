# Manas Pandey — Personal Portfolio

A responsive animated personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` directly in a browser, or run a simple static server:

```bash
python -m http.server 8000
```

Then open http://localhost:8000

## Deploy
Works as-is on GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any static web host.

## Personalize
Edit `index.html` to add project URLs, change copy, or add a downloadable resume button.
